# What Dreamer is / is not

## Is
A pretty place to think with Claude about game ideas: an infinite canvas of cards.
Claude helps:
- **Deepen**: grill, expand, critique.
- **Broaden**: other takes, what-ifs, related.
- **Find inspiration**: web references, visualize.

When an idea is ready, Dreamer hands it off one way: it writes a design-doc pack
into a repo. Claude Code takes it from there, outside Dreamer.

## Is not
- **A build tool**: no build runs, tasks, board, repo scan, Claude Code questions,
  outbox, needs-rebuild.
- **A version manager**: no project versions, folders, design-pack versions.
- **A capture/tray utility**: no global hotkey, Inbox, clipboard-to-Inbox, tray,
  autostart.
- **A local-model host**: no Ollama.

Anything on the "is not" list is out of scope. Say so instead of building it.
